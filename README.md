# РЕСК — лендинг

Статический сайт Российской Единой Сервисной Компании. Готовые файлы находятся в `dist/`; сборка и Node.js на сервере не нужны.

Локальный просмотр:

```bash
python -m http.server 8765 --directory dist
```

Открыть http://127.0.0.1:8765/.

Тестовая публикация для согласования: [GITHUB-PAGES.md](GITHUB-PAGES.md). Готовый workflow: `.github/workflows/pages.yml`.

Порядок публикации на VPS: [MANUAL.md](MANUAL.md). Конфигурация Caddy: `deploy/resk.caddy`.

Домен: `реск.рф`, техническая запись: `xn--e1akqf.xn--p1ai`.

Изображения иллюстрируют услуги, а не подтверждают реальные объекты компании. `sanatorium.webp` — созданная для сайта иллюстрация. Показатели руководителей отражают их профессиональный опыт. Форма запроса сохраняет локальный текстовый файл; отправка в РЕСК пока не подключена.
