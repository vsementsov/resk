Меню: Компания · Услуги · Поставщикам · Карьера · Контакты.
На главной четыре смысловых блока; подробности доступны по ссылкам.
Каждая услуга имеет собственный адрес, H1, title, description, перечень работ,
типы объектов, исходные данные для обсуждения и ссылки на смежные услуги.
Текст страниц присутствует в HTML и не зависит от исполнения JavaScript.
Относительные пути поддерживают размещение в подпапке GitHub Pages.

## Обновление

Готовые файлы находятся в `dist/`, серверу сборка не нужна.
Для повторной генерации после редактирования содержания:

```bash
python3 tools/build_site.py
```

Содержание новой архитектуры и общий шаблон — в `tools/build_site.py`.
Секции предыдущего лендинга сохранены в `content/original-landing.html`.
Стили новой версии — `dist/architecture.css`, базовые стили — `dist/style.css`.
Прямые правки HTML в `dist/` будут перезаписаны генератором.

## Локальный просмотр

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8765/ .

## Индексация и публикация

По умолчанию все страницы содержат `noindex,follow`: это версия для согласования.
robots.txt разрешает обход, чтобы поисковый робот мог увидеть noindex.
Промежуточная публикация на GitHub Pages должна сохранять этот режим.

Когда подтверждены основной адрес, содержание и готовность сайта к индексации:

```bash
python3 tools/build_site.py --base-url https://xn--e1akqf.xn--p1ai/
```

Команда включает index,follow, формирует абсолютные canonical/og:url,
`sitemap.xml` и ссылку на карту сайта в `robots.txt`.
Указанный домен принадлежит пользователю, но команда не означает, что его DNS,
HTTPS или VPS уже настроены. Сначала подтвердить выбранный адрес публикации.
Для размещения в подпапке передать полный базовый URL вместе с подпапкой.
После генерации публиковать именно обновлённую `dist/`.
Дальше добавить основной сайт в Яндекс Вебмастер / Google Search Console,
проверить индексацию и настроить перенаправления со старых URL при необходимости.
SEO-основа не гарантирует позиции: понадобятся подтверждённые материалы,
данные о географии, фактические кейсы и развитие содержания под спрос.

## Что подтвердить перед основной публикацией

- Телефон, email, адрес и реквизиты компании.
- Условия сотрудничества с поставщиками и действующий канал обращений.
- Наличие вакансий, условия работы и контакт для кандидатов.
- Перечни услуг и утверждения о регламентах / качестве.
- Реальные проекты и право на публикацию материалов, если добавляются кейсы.

Фото иллюстрируют направления и не подтверждают реальные объекты РЕСК.
Изображение санатория — иллюстрация. Опыт команды относится к руководителям.
Форма скачивает локальный .txt; email и CRM не подключены.

Старые ZIP-архивы относятся к предыдущему лендингу. Для новой публикации
использовать текущую `dist/`; старые архивы пока не обновлены.
